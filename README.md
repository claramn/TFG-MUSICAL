# TFG-MUSICAL
Generación de timbres musicales mediante redes neuronales

## organización:
- `docs/`: Documentación del proyecto
    * `ideas.md`: ideas generales
    * `reg.md`: registro de avances de cada uno
    * `TODOs.md`: tareas por hacer
- `notebooks/`: Notebooks Jupyter con las pruebas y experimentos
- `src/`: Código fuente del proyecto
    * `utils/`: 
    * `datasets.py`: carga y preprocesamiento de datos
    * `models.py`: definición de los modelos VAE y los autoencoders
- `examples/`:  Ejemplos de audios de resultados
    * `AE/`: autoencoders
    * `VAE/`: variational autoencoders
